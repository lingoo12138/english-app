# 即刻贴文 (产品/学习社区) — 200 字口语版

**标题**: 一个人 22 周做了个英语学习 PWA, 5423 词全本地, 装上就是 offline App

---

搞了个英语学习 App, 拿了些数字给你看, 不打榜不吹牛.

**📊 数字**
- 5,423 词全收录, 主流学段 100% 覆盖 (小学 → 考研)
- 1,941 单元测试 / 23 e2e / 42 次大 review
- Lighthouse: a11y 满分 1.00, 性能 0.89, LCP 1.7s
- 0 emoji 硬编码, 0 网络上传, 0 第三方追踪
- 数据全在本地 IndexedDB, 装上就是 PWA, 离线能用

**💡 解决了什么**
"想用英语的时候就能用上"——不是"打卡完就再也不打开". 我不想学英语, 但我想用英语.

**🎯 8 大功能**
1. 词库 5,423 词 + 字母索引 + 模糊搜索
2. 跟读评测 (自己发音, 系统打分)
3. 错题本 (FSRS 间隔重复)
4. 写作批改 (粘贴文本, AI 帮你纠错)
5. AI 对话 (跟 AI 练英语, 不用花钱)
6. 同义词 / 反义词 / 词根联想
7. 学习日历 (GitHub 风格热力图)
8. 周报 (7 天学习总结, 可分享)
