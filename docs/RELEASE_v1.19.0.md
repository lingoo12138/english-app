## 🛠️ 技术决策

### 为何复用 v1.11 learningReport?
- 数据源已建 (动作数/词数/鼓励)
- 零额外存储
- 一次查询, 多页面用

### 为何热力图 0-4 等级?
- GitHub 风格, 用户熟悉
- 5 等级足够区分 (0=无, 4=重度)
- 颜色 emerald 系列 (积极色调)

### 为何 6 周 (42 格)?
- 任何月 (28-31) 最多跨 6 周
- 固定 42 格避免抖动布局
- 周日-周六 7 列标准

### 为何 hover tooltip 而非点击?
- 月历只展示概览
- 详细数据去 /reports
- 减少点击负担

### 为何 "今天" 按钮?
- 用户常在历史月份, 快速回当月
- 复用 Home 入口逻辑

### 为何复用 Date API (不引 date-fns)?
- 零依赖
- Date API 够用 (月历/格式化)
- 减少 bundle size
