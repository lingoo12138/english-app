## 群内每日提醒 (W149 内测期间)

### D1 (周一)

```
[内测 D1/7] 用了吗?

今天的目标:
- 打开 https://lingoo12138.github.io/english-app/
- 装上 PWA (Chrome/Edge 右上角安装按钮, 或 Safari 分享 → 添加到主屏)
- 看 Home 页面, 点"今日学 5 词"完成 1 次学习

完成后回个 emoji ✅
```

### D2 (周二)

```
[内测 D2/7] 词库 + 错题

今天的目标:
- 打开"词库" — 看看 5,423 词怎么查 (搜 abandon 试试)
- 打开"错题复习" — 看看 4 入口 (写作/听写/拼写/跟读)

如果卡住, 截图发我, 或用 App 右下角"反馈"按钮.
```

### D3 (周三)

```
[内测 D3/7] 暗色 + 快捷键

今天的目标:
- 试试"?" 键 — 打开快捷键面板
- 试试 "g h" (跳首页) / "g w" (跳词库) / "j/k" (词表上下移动)
- 试试"设置 → 主题" — 切到暗色

暗色好看吗? 快捷键好用吗?
```

### D4 (周四)

```
[内测 D4/7] 写一段英文

今天的目标:
- 打开"写作批改" — 粘贴 50-100 词英文 (随便写)
- 让 AI 帮你纠错
- 看错误是否进错题本

你平时会写英文吗? 这个功能对你有用吗?
```

### D5 (周五)

```
[内测 D5/7] 周报

今天的目标:
- 打开"学习周报" (Home → 分享 → 学习周报)
- 看看 7 天学习数据汇总
- 试着分享给朋友

周报有意思吗? 还会想看吗?
```

### D6 (周六)

```
[内测 D6/7] 自由

今天随便用. 用你最常用的功能, 看看哪里让你想骂, 哪里让你惊喜.
```

### D7 (周日)

```

1 周结束了! 你的总体感受:
```
