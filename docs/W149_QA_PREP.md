## 2. 反馈分类标准

### P0 (24 小时内修)
- 完全无法使用某个核心功能
- 数据丢失 / 闪退
- 安全 / 隐私问题
- 安装 PWA 后无法启动

### P1 (周末汇总, W150 修)
- 用户能用但明显不爽
- 体验卡顿
- 找东西找不到
- 暗色 / 主题 bug

### P2 (攒到 W150+)
- 视觉 / 文案 / 小 bug
- 不影响核心体验
- "希望加个 XX" 类

### 夸 (W150 维持 + README 致谢)
- "好用"
- "好看"
- "我会继续用"

## 3. 主人应对手册

### 朋友 A 说 "Home 加载慢"

1. 让朋友截图 + 打开 dev tools → Network
2. 看 LCP / FID / TBT
3. 如果 LCP > 4s: 立即看 (W143 之前可能重现)
4. 如果只是首次加载慢: 解释 PWA 缓存机制
5. 24 小时内回

### 朋友 B 说 "找不到错题复习"

1. 让朋友描述 "你想做什么"
2. 看: Home → 复习 → 错题复习? 还是 Home → 错题本 → 复习?
3. 实际检查 UI 路径
4. 如果是文案 / 导航问题: 立即改文案
5. 24 小时内回

### 朋友 C 说 "暗色字体看不清"

1. 让朋友截图
2. 看具体页面 + 字号
3. W144 已知 a11y 0 fail, 但用户用着不爽可能不一样
4. 立即改
5. 1 天内回

### 朋友 D 说 "我会继续用"

1. 谢谢 🙏
2. 加 README 致谢 (W150)
3. 问 "你最常用哪个功能?"
4. 周末汇总
