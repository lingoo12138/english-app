## 范围

### P1 (主功能): TXT/MD 文件上传
**文件改动**:
- `src/lib/fileUpload.ts` (~120 行, 新):
  - `SUPPORTED_TYPES` 数组: `.txt`, `.md`
  - `MAX_FILE_SIZE = 1MB` (1024 * 1024)
  - `readTextFile(file)`: 读 File → 文本
    - 用 FileReader API
    - 自动截断到 MAX_TEXT_LEN (10000 字符)
  - `validateFile(file)`: 验证类型 + 大小
    - 返 { valid: bool, error?: string }
  - `extractFileName(title)`: 从文件名提取标题 (去扩展名 + 截断)

- `src/pages/CustomScenes.tsx` (改):
  - 加 "📁 上传文件" 按钮
  - 隐藏 `<input type="file">`, 按钮触发点击
  - 接受 .txt / .md
  - onChange: 读文件 → 设置 text state
  - 上传后显示文件名 + 字符数

### P2 (小优化): UX
- 拖放上传 (drag & drop)
- 多文件 (单次最多 3 个)
- 大文件友好提示
