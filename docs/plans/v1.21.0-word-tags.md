## 范围

### P1 (主功能): 标签管理
**文件改动**:
- `src/lib/db.ts` (改): IDB v6 加 `wordTags` 表
  - `wordId, tag, addedAt` (compound index)
  - `addWordTag` / `getWordTags` / `getWordsByTag` / `getAllTags` / `removeWordTag` / `removeAllTagsForWord`

- `src/lib/wordTags.ts` (~150 行, 新):
  - `parseTagInput(input)`: 解析 "tag1, tag2" → ["tag1", "tag2"]
    - 去重, 去除空白, 限制长度 (≤ 20 chars)
    - 小写化
  - `addTagsToWord(wordId, tags)`: 批量加 tag
    - 跳过已存 (幂等)
  - `removeTagFromWord(wordId, tag)`: 去 tag
  - `getAllTagsWithCount()`: 返 [{ tag, count }]
  - `getWordsByTag(tag)`: 按 tag 返 wordId 列表
  - `filterFavoritesByTag(favorites, tag)`: 过滤
  - `suggestTagsFromWord(word, translation)`: 基于词内容启发式 (e.g. "computer" → "tech")

- `src/pages/Notebook.tsx` (改):
  - 加 tag 显示 (徽章)
