## 范围

### P1 (主功能): 学完入复习
**文件改动**:
- `src/lib/sceneReview.ts` (~100 行, 新):
  - `addSceneWordsToReview(words, sceneTitle)`: 批量入复习
    - 用 v1.11 reviews IDB 表 (`wordId, nextReview`)
    - 用 v1.11 reviewQueue (sortReviewQueue)
    - 跳过已收藏的 (避免重复)
    - 初始 nextReview = now (立即可复习)
    - 初始 easeFactor = 2.5, interval = 0
  - `getSceneReviewStatus(sceneId)`: 取场景复习状态
    - { totalWords, inReviewCount, masteredCount }
  - `removeSceneWordsFromReview(sceneId)`: 删除场景时同步清复习

- `src/pages/CustomSceneLearn.tsx` (改):
  - 完成时调 `addSceneWordsToReview(words, scene.title)`
  - Toast 提示 "🎉 N 词已加入复习队列"
  - 不阻塞完成态

- `src/pages/CustomSceneDetail.tsx` (改):
  - 顶部加 "📊 复习状态" 卡片
  - 显示: totalWords / inReviewCount / masteredCount
  - 复用 useEffect 加载状态

- `src/pages/CustomScenes.tsx` (改):
  - 列表项加 "📚 N 复习中" 标签 (inReviewCount)
  - 复用 sceneReview.getSceneReviewStatus
