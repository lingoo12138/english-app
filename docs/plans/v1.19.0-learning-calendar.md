## 范围

### P1 (主功能): 学习日历页面
**文件改动**:
- `src/lib/learningCalendar.ts` (~150 行, 新):
  - `getCalendarMonth(year, month)`: 取月历数据
    - 7×N 网格 (周日-周六)
    - 每格: { date, dayOfMonth, isCurrentMonth, actionCount, wordCount, studyTime }
    - 复用 learningReport.getDailyReport
  - `getMonthActionCount(year, month)`: 月累计动作数
  - `getMonthWordCount(year, month)`: 月累计词数
  - `getHeatmapLevel(count)`: 0-4 配色等级 (0=无, 4=活跃)
  - `formatDateKey(date)`: YYYY-MM-DD
  - `getMonthName(month)`: "2026 年 7 月"

- `src/pages/CalendarPage.tsx` (~200 行, 新):
  - URL 路由 /calendar
  - 状态: year, month (默认当前)
  - 顶部: 月份标题 + ← → 切换按钮
  - 7 列网格 (周日-周六 表头)
  - 每格: 日期数字 + 动作数 + 配色 (热力图)
  - 配色等级:
    - 0 = 灰 (无学习)
    - 1 = 浅绿 (1-5 动作)
    - 2 = 绿 (6-15)
    - 3 = 深绿 (16-30)
    - 4 = 翠绿 (31+)
  - hover tooltip: "X 月 Y 日 - 动作 N 个, 词 M 个, 学习 T 分钟"
  - 月度统计卡片: 动作总数 / 词总数 / 学习天数

- `src/App.tsx` (改):
  - 加路由 /calendar (lazy load)

- `src/pages/Home.tsx` (改):
  - 加 "📅 学习日历" 入口卡片
