## 范围

### P1 (主功能): 生词本批量操作
**文件改动**:
- `src/lib/notebookBulk.ts` (~120 行, 新):
  - `addFavoritesToReview(favorites)`: 批量入复习
    - 复用 v1.11 reviews 表, 用 wordId 作 key
    - 跳过已存 (幂等)
    - 返 { added, skipped, failed }
  - `removeFavorites(favorites)`: 批量删除收藏
    - 返 { removed, failed }
  - `exportFavoritesAsCSV(favorites)`: 导出 CSV
    - 格式: word,translation,difficulty,addedAt
    - 返 Blob URL
  - `selectAll(allFavorites)`: 全选辅助
  - `invertSelection(current, all)`: 反选辅助

- `src/pages/Notebook.tsx` (改):
  - 加 "选择模式" 切换按钮
  - 多选 checkbox (每条词)
  - 选中统计 + 顶部操作栏
  - 操作: 全部入复习 / 批量删除 / 导出 CSV
  - 状态: selectedIds: Set<string>
