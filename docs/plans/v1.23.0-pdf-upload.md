## 范围

### P1 (主功能): PDF 解析
**文件改动**:
- `src/lib/pdfUpload.ts` (~150 行, 新):
  - `extractPdfText(file)`: 用 pdfjs-dist 解析 PDF
    - 懒加载 pdfjs (dynamic import, 不增加初始 bundle)
    - 提取所有页文本
    - 合并 + 去多余空白
  - `validatePdfFile(file)`: 验证 PDF
    - 扩展 v1.18.0 validateFile 加 .pdf
    - 检查文件签名 `%PDF-`
    - 大小限制同 (1MB)
  - `getPdfPageCount(file)`: 取页数 (用于 UI 提示)
  - `isPdfEncryptedError(e)`: 检测加密 PDF 错误

- `src/lib/fileUpload.ts` (改):
  - SUPPORTED_EXTENSIONS 加 `.pdf`
  - SUPPORTED_MIME_TYPES 加 `application/pdf`
  - 导出 PDF 解析函数 (从 pdfUpload)
  - 文档说明: PDF 解析在用户点击时懒加载

- `src/pages/CustomScenes.tsx` (改):
  - accept 加 `,.pdf`
  - file 类型判断 (TXT/MD/PDF 走不同路径)
  - PDF: 提示 "解析中..." + 懒加载 pdfjs
  - 加密 PDF / 解析失败友好提示

### P2 (小优化): UX
- PDF 页数显示 ("15 页 PDF")
- 大 PDF 进度提示
- 多文件 (单次最多 3 个, PDF 暂不支持多文件, 因为太慢)
