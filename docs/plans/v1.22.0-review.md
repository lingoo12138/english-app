## Review 步骤

### 1. 静态审查 (5 维度)
1. **类型守卫**: 找 `catch (e: any)` 残余
2. **setLoading 配对**: 找 setLoading(true) 缺 false
3. **useEffect 依赖**: 找 `useEffect(() => {}, [])` 缺依赖
4. **a11y**: 找缺 aria-label 按钮
5. **错误处理**: 找 `.catch(() => {})` 空 catch

### 2. 运行时测试
- 跑全部 510 单元测试, 看是否全过
- 跑 build, 看是否成功
- 跑 verify + review 脚本

### 3. 代码搜索
- 找 `as any` 残余
- 找 `console.error` 不打 Toast
- 找空函数实现
- 找重复代码

### 4. UX 一致性
- 所有页面有 loading 状态
- 所有页面有 empty 状态
- 所有页面有 error 状态
- 按钮文案统一

### 5. 输出
- `docs/REVIEW_v1.22.0.md` 类似 v1.6 报告
- 分类 P0/P1/P2 bug
- 修前几个最高优
