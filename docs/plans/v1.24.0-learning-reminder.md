## 升级点 (3 件, ROI 排序)

### A. 动态内容 (⭐ 最高 ROI)

**改 `fireReminderNotification` 复用 reviewQueue + learningReport**:

```ts
// 通知正文根据当日数据动态生成
async function buildReminderBody(): Promise<string> {
  const today = new Date().toISOString().slice(0, 10)  // YYYY-MM-DD
  const dueCount = await getReviewsByDate(today).then(r => r.length)  // 今日到期
  const newWords = await getNewWordsForToday().then(w => w.length)   // 今日新词
  const minutes = (dueCount * 0.5 + newWords * 0.3) | 0  // 估算时间

  if (dueCount === 0 && newWords === 0) {
    return '今天 0 个复习, 学 3 个新词 1 分钟搞定'
  }
  if (dueCount > 0) {
    return `${dueCount} 个复习${newWords ? ` + ${newWords} 个新词` : ''}, ${minutes} 分钟搞定`
  }
  return `${newWords} 个新词, ${minutes} 分钟搞定`
}
```

### C. 不活跃用户召回 (⭐ 高 ROI)

**复用 reviewQueue + learningReport 检测 3 天未学**:

```ts
async function getDaysInactive(): Promise<number> {
  const lastDate = await getLastStudyDate()  // 从 records 表查
  if (!lastDate) return 0
  const days = (Date.now() - lastDate) / 86_400_000
  return Math.floor(days)
}

// body 优先级
if (daysInactive >= 3) {
  return `别断! 3 天前你学了 5 个词, 今天 5 分钟恢复一下`
} else if (dueCount > 0) {
  return `${dueCount} 个复习, ${minutes} 分钟搞定`
} else if (newWords > 0) {
  return `${newWords} 个新词, ${minutes} 分钟搞定`
} else {
  return '今天 0 个复习, 学 3 个新词 1 分钟搞定'
}
```

**新增函数 `getLastStudyDate()`** (复用 IndexedDB records 表):
```ts
export async function getLastStudyDate(): Promise<number | null> {
  const rec = await db.records.orderBy('ts').reverse().first()
  return rec?.ts ?? null
}
```
