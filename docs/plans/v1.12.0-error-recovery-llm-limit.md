### P2: v1.12.0-B 错误恢复 / 离线降级 (C6, 1d)
- **Why**: LLM 挂掉零提示, 用户困惑
- **Scope**:
  - `src/lib/llmFallback.ts` (~50 行):
    - `withFallback(primaryFn, fallbackFn)`: try-catch + 友好降级
    - 错误类型分类: network / rate_limit / auth / unknown
    - 友好提示: "网络异常, 已切换 Mock" / "API key 失效, 请检查设置"
  - `src/components/ErrorBoundary.tsx` 改造 (v0.28 已有):
    - 错误时显示 "🆘 出错了" + 重试按钮 + 切 Mock 渠道 CTA
  - LLM 调 5 处包裹 withFallback:
    - WritePage handleReview
    - AIChat handleSend
    - ErrorExplainButton handleClick
    - UsageButton handleClick
    - GrammarButton handleClick
  - `tests/llmFallback.test.ts` (4 测试):
    - withFallback 主函数成功 → 不调 fallback
    - 主函数失败 → 调 fallback
    - 错误分类
    - 友好提示

### P3: v1.12.0-C LLM 成本控制 (C7, 1d)
- **Why**: LLM 调日限, 防止滥用
- **Scope**:
  - `src/lib/llmUsage.ts` (~80 行):
    - `LLM_USAGE_KEY = 'llm-usage'`
    - `recordLLMCall(category)`: 累加今日调用数
    - `getLLMUsageToday(category)`: 今日调用数
    - `getDailyLimit(category)`: 各类别日限 (写 20, AI 对话 50, 讲解 30)
    - `checkLLMLimit(category)`: 检查是否超限
  - `src/pages/Settings.tsx` 加 "📊 LLM 用量" 卡片:
    - 今日调用数 / 日限 / 剩余
    - 按 category 分 (写作/对话/讲解)
    - 进度条
  - 5 处 LLM 调前加 checkLLMLimit (超限返友好提示)
  - `tests/llmUsage.test.ts` (4 测试):
    - recordLLMCall 累加
    - getLLMUsageToday 跨日重置
    - checkLLMLimit 超限
    - getDailyLimit 各 category
