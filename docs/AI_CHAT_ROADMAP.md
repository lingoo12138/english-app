## 进阶候选(按价值排序)

### 1. 🎤 语音输入(高价值,优先) - ⏳ 暂未做

- **目标**: 取代键盘输入,像真人对话
- **现有**: v0.11 STT 渠道 (Web Speech API) + PronunciationPractice (录音)
- **实现**: MediaRecorder 录 5-10s 音频 → 转 base64 → LLM Vision/Whisper → 转文字
- **依赖**: LLM 渠道(OpenAI Whisper / Gemini 音频)或独立 STT 渠道
- **UI**: 输入区加 🎙 按钮,按住录音,松手发送
- **场景**: 练发音 + 测理解双管齐下

### 2. 💾 对话持久化 + 历史记录 - ✅ v1.0 完成

- ✅ IndexedDB `chats` 表 (id, scenario, level, messages[], ts)
- ✅ `/chat` 页面"📚 历史"按钮 + 删除/导出
- ✅ 导出 JSON (v0.22.8)
- 数据: 每条对话 ~2KB

### 3. 📊 学习报告 + 错题分析 - ✅ v1.11 完成

- ✅ ReportsPage /reports 路由
- ✅ 日报 + 周报 + 趋势对比 (含 direction 字段)
- ✅ ErrorsPage 错题列表
- ✅ 鼓励文案 + 同周对比

### 4. 🔄 多角色 / 多人对话 - ⏳ 暂未做

- 目标: 模拟多人场景(如点菜时朋友+服务员+你)
- 实现: System prompt 指定多个 NPC, 轮流回复
- v1.13 已支持单角色, 多人需多角色 system prompt 组合

### 5. 🎯 自由话题 / 角色扮演 - ✅ v1.9 完成

- ✅ "💬 自由话题" 按钮 + 200 字符输入
- ✅ truncateCustomTopic 截断
- ✅ aiChat.ts 集成

### 6. 🌐 实时纠错 + 提示 - ✅ v1.10 完成

- ✅ ErrorExplainButton (单条纠错)
- ✅ UsageButton / GrammarButton / SynonymsButton (4 个讲解按钮)
- ✅ reviewMessage 后台纠错 (v1.0)
- ✅ 错题解释缓存 (v1.2-D2)

### 7. 🗣 发音评测 - ✅ v0.22 + PronunciationPractice 组件

- **目标**: 语音输入时给发音打分
- **实现**: 复用现有 PronunciationPractice 组件
- **集成**: 跟 #1 语音输入一起做

### 8. 📚 对话中单词收藏

- **目标**: 看到生词直接收藏,带上下文例句
- **实现**: 长按消息中单词 → 弹收藏窗 → 写 favorites 表
- **UI**: 单词高亮 + 翻译 tooltip

### 9. 🌙 离线对话(PWA 缓存)

- **目标**: 飞机模式也能练
- **实现**: 预生成常见对话脚本(每个场景 50 套),本地随机抽取
- **本质**: 扩展 Mock 渠道,加脚本库

### 10. 🧪 难度自适应

- **目标**: 不让用户手动选,LLM 自动调难度
- **实现**: 监测用户表达平均长度 / 词汇复杂度,动态调整 system prompt
- **算法**: 简单规则(消息长度 < 5 词 → 降级;> 15 词 → 升级)

## 待决问题(用户思考)

1. **数据归属**: 对话历史算学习记录吗?清空数据是否包括?
2. **隐私**: 对话内容是否本地?还是默认匿名上传 LLM?
3. **付费策略**: 高级报告 / 永久历史是否会员制?
4. **离线策略**: 是否支持"无 LLM 也能练"?
5. **多模态顺序**: 先做语音输入还是先做发音评测?

## 实现顺序建议

按 ROI 排序:

1. **#1 语音输入** + #7 发音评测(共用录音链路,一次实现双功能)
2. **#2 对话持久化**(让功能"留下来",不流失)
3. **#6 实时纠错**(核心学习价值)
4. **#3 学习报告**(留存 + 商业化潜力)
5. 其余按需
