## 6. 战略调整 (W150+)

W149 数据 → W150+ 战略:

- [ ] **如果反馈 OK (NPS ≥ 7, 反馈 ≥ 10 条, 完成 7 天 ≥ 3 人)**:
  - W150: 修 P0/P1
  - W151: 公开发布 + 博客
  - W152+: 持续内测 + 修 P2 + 文档

- [ ] **如果反馈差 (NPS ≤ 5, 差评 ≥ 30%)**:
  - W150: 大改版 (回 v3 战略 review)
  - W151: 复测
  - W152+: 决定收尾 / 继续 / 开源

- [ ] **如果 0 反馈 (0 完成 7 天)**:
  - W150: 文档收尾 + 博客 (本博客就是)
  - W151: 决定开源
  - W152+: W151 决定
