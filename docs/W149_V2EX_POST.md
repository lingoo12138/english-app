### 它是什么

不卖课. 不连云. 不上传数据. **数据全在浏览器 IndexedDB**. 装上就是 PWA, 离线可用.

### 解决了什么

- 想用英语的时候"想用就用得上"——不是"今天打卡 50 词然后再也不打开"
- FSRS 间隔重复, 跟读评测, 同义词/反义词/词根联想
- 跟写写作 / AI 对话实时纠错
- 错题本 + 7 天复习曲线

### 数字说话 (你看了就知道这玩意儿不是 demo)

- **5,423 词 / 100% 覆盖** 主流学段 (小学/初中/高中/CET-4/CET-6/考研/日常)
- **8 大功能**: 词库 / 跟读 / 错题复习 / 同义词 / 写作批改 / AI 对话 / 学习日历 / 周报
- **1,941 单元测试 / 23 e2e** 覆盖业务关键路径
- **Lighthouse**: perf 0.89 / a11y 满分 1.00 / LCP 1.7s
- **42 次大 review** (W132-W148), 累计 28+ 独立 verifier 抗审查
- **0 emoji 硬编码** / **0 网络上传** / **0 第三方追踪**

### 适合谁
